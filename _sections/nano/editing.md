#### Mark a region

```
^Space          set mark (start selection)
Arrow keys      extend selection
M-A             toggle mark
```

#### Cut & paste

```
^K              cut line (or marked region)
M-6             copy line (or marked region)
^U              paste
```

#### Undo & redo

```
M-U             undo
M-E             redo
```
