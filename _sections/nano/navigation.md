#### Basic movement

```
Arrow keys      move cursor
^A              beginning of line
^E              end of line
M-\             beginning of file
M-/             end of file
```

#### Jump

```
^Y / ^V         page up / page down
^_              go to line number
M-G             go to line (alias for ^_)
```
