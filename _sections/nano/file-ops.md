#### Save & quit

```
^O              write/save file
^X              exit (prompts if modified)
^X then Y       save and exit
^X then N       exit without saving
```

#### Other

```
^R              insert another file at cursor
^C              show cursor position
M-N             toggle line numbers
M-P             toggle whitespace display
```
