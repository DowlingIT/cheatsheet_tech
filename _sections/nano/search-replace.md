#### Search

```
^W              open search prompt
M-W             repeat search (forward)
M-Q             repeat search (backward)
^W^R            toggle regex in search
```

#### Replace

```
^\              open search & replace
```

At the replace prompt: enter search string → Enter, then replacement → Enter. Press `Y`/`N` per match or `A` for all.
