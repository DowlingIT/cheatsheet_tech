#### Basic

```
h j k l         left / down / up / right
w               next word start
b               previous word start
e               end of word
```

#### Line

```
0               line start
^               first non-blank char
$               line end
```

#### File

```
gg              top of file
G               bottom of file
:<n>            go to line n
Ctrl+F          page down
Ctrl+B          page up
%               jump to matching bracket
```
