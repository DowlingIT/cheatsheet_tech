#### Delete

```
x               delete char under cursor
dd              delete line
dw              delete word
d$              delete to end of line
```

#### Yank & paste

```
yy              yank (copy) line
yw              yank word
p               paste after cursor
P               paste before cursor
```

#### Change & undo

```
cc              change (replace) line
cw              change word
r               replace single char
u               undo
Ctrl+R          redo
.               repeat last command
```

#### Indent

```
>>              indent line
<<              dedent line
```
