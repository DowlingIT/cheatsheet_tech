#### Enter visual mode

```
v               character selection
V               line selection
Ctrl+V          block selection
```

#### Act on selection

```
y               yank (copy)
d               delete (cut)
c               change (delete & insert)
>               indent
<               dedent
~               toggle case
:               run command on selection
```
