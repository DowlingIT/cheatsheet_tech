#### Return to Normal

```
Esc             return to Normal from any mode
```

#### Enter Insert mode

```
i               insert before cursor
a               insert after cursor
I               insert at line start
A               insert at line end
o               open new line below
O               open new line above
```

#### Other modes

```
v               Visual (character)
V               Visual (line)
Ctrl+V          Visual (block)
:               Command-line
R               Replace
```
