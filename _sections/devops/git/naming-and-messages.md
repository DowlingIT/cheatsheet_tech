#### Branch naming conventions

Prefixes create logical grouping in tools and listings.

- `feature/<name>` &mdash; new functionality
- `bugfix/<name>` &mdash; fixing a bug
- `hotfix/<name>` &mdash; urgent production fix
- `release/<name>` &mdash; preparing a release
- `chore/<name>` &mdash; maintenance, docs

#### Commit message conventions

```
feat: add user authentication
fix: prevent null pointer on login
docs: update API reference
refactor: extract validation logic
```
