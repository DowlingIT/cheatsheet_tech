#### Diff a file since a commit

```
git diff <commit> -- <file>
```

#### Summary of changes

```
git diff <commit> --stat
```

#### Show a specific commit

```
git show <commit>
```

#### Diff two commits

```
git diff <commit1> <commit2>
```
