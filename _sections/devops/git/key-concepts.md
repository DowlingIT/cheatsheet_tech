- **repository** &mdash; a project folder tracked by Git with full change history
- **commit** &mdash; a snapshot of staged changes with a descriptive message
- **branch** &mdash; a movable pointer to a commit; isolates work
- **HEAD** &mdash; pointer to your current commit (usually tip of a branch)
- **staging area** &mdash; where you prepare changes before committing (`git add`)
- **remote** &mdash; a repo hosted elsewhere (e.g. GitHub); `origin` is the default
- **tracking branch** &mdash; local branch linked to a remote for easy push/pull
- **fast-forward** &mdash; merge where the pointer just moves forward (no new commit)
- **stash** &mdash; temporary shelf for uncommitted changes
- **reflog** &mdash; log of everywhere HEAD has pointed; safety net for lost commits
