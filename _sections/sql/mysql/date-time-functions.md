#### Common functions

```sql
NOW()   CURDATE()   CURTIME()
DATEDIFF(end_date, start_date)
DATE_ADD(order_date, INTERVAL 7 DAY)
YEAR(order_date)   MONTH(order_date)   DAY(order_date)
DATE_FORMAT(order_date, '%Y-%m-%d')
```
