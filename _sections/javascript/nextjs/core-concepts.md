#### Terms

```
App Router       file-based routing under app/ — Server Components by default
Pages Router       legacy file-based routing under pages/ — Client Components by default
Server Component      renders on the server, ships no JS to the client (default in app/)
Client Component        renders in the browser — opt in with 'use client'
Route segment              a folder in app/ that maps to a URL segment
Hydration                    client-side React attaching to server-rendered HTML
```
