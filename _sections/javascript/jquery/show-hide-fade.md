#### Built-in effects

```js
$el.show()   $el.hide()   $el.toggle()
$el.fadeIn()   $el.fadeOut()   $el.fadeToggle()
$el.slideDown()   $el.slideUp()   $el.slideToggle()
$el.fadeIn(400, () => console.log('done'));   // duration + callback
```
