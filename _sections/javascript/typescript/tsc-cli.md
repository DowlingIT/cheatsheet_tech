#### Commands

```bash
tsc                     # compile using tsconfig.json
tsc --init                # generate a starter tsconfig.json
tsc --watch                 # recompile on file changes
tsc --noEmit                  # type-check only, no output files
npx tsc file.ts --outDir dist
```
