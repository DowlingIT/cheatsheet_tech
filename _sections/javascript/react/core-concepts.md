#### Terms

```
JSX             HTML-like syntax that compiles to React.createElement calls
Component        function (or class) that returns JSX
Props              read-only inputs passed from a parent to a component
State                data owned by a component that triggers a re-render on change
Virtual DOM            in-memory tree React diffs against the real DOM to batch updates
Reconciliation           the diffing process that decides what actually needs to change
key                        stable identity hint for list items — not just an index
```
