#### Web frameworks

```
express       minimal, unopinionated HTTP framework — the de facto standard
fastify         high-performance alternative to Express
koa               lightweight, async-first (built by the Express team)
nestjs              opinionated, TypeScript-first, Angular-style architecture
```

#### Process & dev tooling

```
pm2          production process manager — clustering, restarts, log management
nodemon        restarts the process on file changes (dev only)
dotenv           loads environment variables from a .env file
cross-env          sets env vars in a cross-platform way inside npm scripts
```
