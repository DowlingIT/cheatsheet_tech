#### Math

```js
Math.round(4.5)   Math.floor(4.9)   Math.ceil(4.1)
Math.abs(-5)   Math.max(1, 5, 3)   Math.min(1, 5, 3)
Math.random()          // [0, 1)
Math.pow(2, 10)   2 ** 10
```

#### Number formatting

```js
(1234.5).toFixed(2)          // '1234.50' — returns a string
(255).toString(16)              // 'ff' — base conversion
(1234567).toLocaleString()        // '1,234,567'
Number.isInteger(4)   Number.isFinite(4)
```
