#### Key terms

```
QuerySet        lazy, chainable set of database rows — evaluated on demand
Manager         interface for querying a model (default: Model.objects)
Migration       versioned schema change generated by makemigrations
Field           column type — CharField, IntegerField, ForeignKey, …
related_name    reverse accessor name from the related model
Signal          hook fired on events — pre_save, post_delete, m2m_changed
Fixture         serialized data snapshot loaded with loaddata
```
