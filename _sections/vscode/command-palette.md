Windows/Linux shortcuts shown; replace `Ctrl` with `Cmd` on macOS.

#### Open anything

```
Ctrl+Shift+P    Command Palette (run any command)
Ctrl+P          Quick Open — go to file by name
Ctrl+G          Go to line
Ctrl+Shift+O    Go to symbol in current file
Ctrl+T          Go to symbol in workspace
```
