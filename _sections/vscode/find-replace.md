#### In current file

```
Ctrl+F              Find
Ctrl+H              Replace
F3 / Shift+F3       Next / previous match
Alt+Enter           Select all matches
```

#### Across files

```
Ctrl+Shift+F        Find in files
Ctrl+Shift+H        Replace in files
```
