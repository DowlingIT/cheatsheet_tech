#### strings package

```go
strings.Contains(s, "foo")
strings.HasPrefix(s, "foo")   strings.HasSuffix(s, "foo")
strings.ToUpper(s)   strings.ToLower(s)
strings.TrimSpace(s)
strings.Split(s, ",")   strings.Join(parts, ", ")
strings.Replace(s, "a", "b", -1)   // -1 = replace all
```
