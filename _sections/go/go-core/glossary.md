#### Language terms

```
Goroutine    lightweight thread managed by the Go runtime
Channel      typed pipe for communication between goroutines
Interface    set of method signatures — implemented implicitly
Struct       composite type grouping named fields
Package      unit of code organization — every file belongs to one
Zero value   default value a variable gets when declared without init
```

#### Tooling terms

```
Module            a collection of packages with a go.mod, versioned as a unit
Blank identifier    _ — discards a value you don't need
Receiver               the (t Type) in a method — binds a func to a type
```
